Welcome

FlowStat runs the repeating work of a statistical office, such as the quarterly consolidation of forms from the regions, as a process that is written down once, checked before it starts, and followed step by step.

    How it works

    1. WriteThe process is a short text: steps, what each one needs, and the goal.
    2. CheckMistakes show while you type: a missing input, a loop, a goal that can never be reached.
    3. RunPublish a version and start it. Steps that do not depend on each other run together.
    4. ApproveA step can wait for a person, such as the chief statistician, and the answer is kept.

          Send several forms at once Drop the files here, or choose them. A file is for the region its name says: BIS.xlsx is for BIS.
          RegionFormRowsSizeRules

          A form is an Excel file with the columns code, name and value. It is stored where the workflow reads it. A form that breaks a rule (an empty or repeated code, a value that is not a number or is negative) is accepted and shown here; the check step of the run stops at it.
