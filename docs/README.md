# Documentation

| Document | What it is |
| --- | --- |
| `Project_Proposal.docx` | Project Proposal: requirements, functionality balance (A/B/C), architecture, pseudocode of C1-C6, plan, backlog |
| `Engineering_Playbook.docx` | Working rules, order of work, definition of done, test strategy, report assembly |
| `architecture.md` | Layers, dependency rule, roles of the engine, invariants |
| `engineering-rules.md` | The rules we work by, short form |
| `dsl-spec.md` | DSL specification (EBNF with examples), written at the start of I1 |
| `algorithms/` | One algorithm card per C function |
| `diagrams/` | PlantUML sources |
| `research/` | Benchmarks and their conclusions |
| `process.md` | The cycle of a milestone and the documents kept alive |
| `milestones/` | One file per milestone: goal, stories, review, retrospective |
| `journal.md` | Decision journal |
| `backlog.md` | Live backlog, statuses, burndown |
| `traceability.md` | UR/DR, story, function, design element, test, result |
| `reuse.md` | Reuse ledger and the allow-list of third-party imports |
| `negative-check.md` | Functions we do not count as complex, with the reason |
