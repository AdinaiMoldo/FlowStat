# C6. Predicate solver and test generator

Increment: I4. One page when the function is finished.

## Two levels

- **Level 1 (known algorithm, our transformation):** Difference-graph solver: Bellman-Ford with (constant, strict) edge weights over a DNF with a clause cap; witness values from shortest-path distances.
- **Level 2 (built on the output of level 1):** Test generator: greedy set cover over targets (branches, join outcomes) that level 1 has proved feasible, with a witness input for each.
- **Dependence:** Level 2 needs the proofs and witnesses of level 1; without them it would emit tests for unreachable branches.
- **Baseline for the benchmark:** Random inputs and brute force, against the generator: targets covered per test, by predicate size.
